# README

`README.md` orienta umano e agente nel progetto: identità, dominio, poste e
percorsi per approfondire. Risponde a «dove sono e da dove parto?» senza
diventare manuale, catalogo o modello completo.

## Contenuto

Il dominio ha priorità sulla struttura. Dopo nome e scopo, il README rende
comprensibili:

- il Mondo di cui il progetto si occupa;
- i Goal o le tensioni che lo rendono rilevante;
- i percorsi espressi nel linguaggio del dominio;
- lo stato e il cruscotto corrente;
- le porte verso conoscenza, regole operative, fonti e viste.

Il README sintetizza e rimanda. Modello e principi estesi vivono nei nodi,
Goal e World nei register di root, il catalogo in `kb/kb.md`, il lavoro in
`o1/plan.md` e `o2/`, le istruzioni in `CLAUDE.md`. Procedure, flag,
troubleshooting e inventari completi non appartengono alla bussola.

Una sequenza utile, non obbligatoria, è: identità; dominio; percorsi; stato;
Metodo; struttura essenziale; cautele di dominio. La lunghezza non è un
criterio autonomo: conta il rapporto fra orientamento e dettaglio accumulato.

## Sezione Metodo negli adottanti

La sezione `## Metodo` dichiara una volta la dipendenza generale dal canone:

- breve descrizione del cognitive artifact design;
- symlink `method/` verso i nodi canonici;
- hub stabile `method/cognitive-artifact-design.md`;
- register locali `goal.md` e `world.md`.

Non elenca i nodi interni del metodo. Altrove un link canonico resta soltanto
quando esprime una dipendenza semantica o operativa reale.

## Criteri di revisione

- nei primi minuti sono chiari dominio e posta in gioco?
- i percorsi partono da intenzioni del lettore?
- struttura e strumenti stanno sottraendo spazio al dominio?
- il file punta alle fonti senza duplicarle?
- concorda con `CLAUDE.md`, `goal.md` e `world.md`?

La revisione riguarda questo quartetto nel suo insieme: alleggerire il README
non serve se il contenuto si riversa in CLAUDE o se le intro dei register
contraddicono la bussola. La comparazione corrente vive in
`i2/bootstrap-adottanti.md`; la procedura in
`o3/revisione-bootstrap-adottante.md`.
